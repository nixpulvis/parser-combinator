1 Quick Start🔗

Parsing happens in two steps. First a Parser turns a string into a Value, made of strings for the text that matched and lists for sequences and repetitions. Then an ordinary recursive function turns the Value into the data the program needs.

Take numbers such as "0", "-7", and "140". A number is an optional minus sign followed by either a lone zero or a non-zero digit and any number of further digits:

(require parser-combinator/parse)
 
; Parser
(define-parser NONZERO-DIGIT
  (alt* (lit "1") (lit "2") (lit "3") (lit "4") (lit "5")
        (lit "6") (lit "7") (lit "8") (lit "9")))
 
; Parser
(define-parser DIGIT
  (alt (lit "0") NONZERO-DIGIT))
 
; Parser
(define-parser NUMBER
  (seq* list
        (opt (lit "-"))
        (alt (lit "0")
             (seq cons NONZERO-DIGIT (star DIGIT)))))

Running a parser with parse produces the Value. A missing sign is '():

> (parse NUMBER "-7")

'("-" ("7"))

> (parse NUMBER "140")

'(() ("1" "4" "0"))

To get a number out of the Value, design a function that follows the grammar. Each digit is a string. Unless the number is a lone zero, its digits form a list, which foldl walks from left to right:

; String -> Natural
; computes the value of the digit d
> (define (digit->number d)
    (- (char->integer (string-ref d 0))
       (char->integer #\0)))
  
; String Natural -> Natural
; adds the digit d to the end of n
> (define (add-digit d n)
    (+ (* 10 n) (digit->number d)))
  
; Value -> Natural
; computes the value of the part after the sign
> (define (integer->number v)
    (if (string? v)
        0
        (foldl add-digit 0 v)))
  
; Value -> Integer
; converts the Value of a number into a number
> (define (value->number v)
    (if (string? (car v))
        (- (integer->number (cadr v)))
        (integer->number (cadr v))))
  
> (value->number (parse NUMBER "0"))

0

> (value->number (parse NUMBER "-7"))

-7

> (value->number (parse NUMBER "140"))

140

Input that is not in the grammar is an error:

> (parse NUMBER "007")

bad input, had leftover text "07"

The source of parser-combinator/json skips the second step for a larger grammar: its parsers use seq* constructors to build the data while they parse.
