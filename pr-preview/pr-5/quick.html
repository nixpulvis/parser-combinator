1 Quick Start🔗

Parsing happens in two steps. First a Parser turns a string into an AST. The AST is a tree that records how the grammar matched the input. Then an ordinary recursive function turns the AST into the data the program needs.

Take numbers such as "0", "-7", and "140". A number is an optional minus sign followed by either a lone zero or a non-zero digit and any number of further digits:

(require parser-combinator/parse)
 
; Parser
(define-parser NONZERO-DIGIT
  (alt* (lit "1") (lit "2") (lit "3") (lit "4") (lit "5")
        (lit "6") (lit "7") (lit "8") (lit "9")))
 
; Parser
(define-parser DIGIT
  (alt (lit "0") NONZERO-DIGIT))
 
; Parser
(define-parser NUMBER
  (seq* 'number
        (opt (lit "-"))
        (alt (lit "0")
             (seq 'digits
                  NONZERO-DIGIT
                  (star DIGIT)))))

Running a parser with parse produces the AST:

> (parse NUMBER "-7")

(seq-node

 'number

 (lit-node "-")

 (seq-node 'digits (lit-node "7") (emp-node)))

To get a number out of the AST, design a function that follows the grammar. Each digit is a lit-node. The digits after the first one form a star chain. The function star-foldl walks that chain from left to right:

; AST -> Natural
; computes the value of the digit that ast matched
> (define (digit->number ast)
    (- (char->integer (string-ref (lit-node-value ast) 0))
       (char->integer #\0)))
  
; AST Natural -> Natural
; adds the digit d to the end of n
> (define (add-digit d n)
    (+ (* 10 n) (digit->number d)))
  
; AST -> Natural
; computes the value of the part after the sign
> (define (integer->number ast)
    (cond [(lit-node? ast) 0]
          [else
           (star-foldl add-digit
                       (digit->number (seq-node-left ast))
                       (seq-node-right ast))]))
  
; AST -> Integer
; converts the AST of a number into a number
> (define (ast->number ast)
    (if (lit-node? (seq-node-left ast))
        (- (integer->number (seq-node-right ast)))
        (integer->number (seq-node-right ast))))
  
> (ast->number (parse NUMBER "0"))

0

> (ast->number (parse NUMBER "-7"))

-7

> (ast->number (parse NUMBER "140"))

140

Input that is not in the grammar is an error:

> (parse NUMBER "007")

bad input, had leftover text "07"
