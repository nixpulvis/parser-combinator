Parser Combinator🔗

Nathan Lilienthal

This package provides a small library of parser combinators: functions that consume parsers and produce new parsers. Each parser is a Racket function from a string to a result, so a grammar is written as a collection of plain definitions, one per non-terminal.

The package comes with two libraries:

  • parser-combinator/parse, combinators for building parsers

  • parser-combinator/json, a JSON parser
